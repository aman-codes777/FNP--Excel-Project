# 📊 FNP Sales Analysis Dashboard -- Excel

## 📌 Project Overview

An interactive **Sales Analysis Dashboard** created in Microsoft Excel
to analyze FNP sales performance. The dashboard converts raw sales data
into meaningful KPIs, charts, and interactive slicers for quick business
insights.

## 🎯 Key KPIs

* 🛒 **Total Orders:** 1,000
* 💰 **Total Revenue:** ₹35,20,984
* ⏱️ **Average Order-Delivery Time:** 5.53
* 👤 **Average Customer Spending:** ₹3,520.98

## 📈 Dashboard Visualizations

* 💝 Revenue by Occasion
* 🏷️ Revenue by Category
* 🕐 Revenue by Order Hour
* 📅 Revenue by Month
* 🏆 Top 5 Products by Revenue
* 🌆 Top 10 Cities by Orders

## 🎛️ Interactive Filters

The dashboard includes interactive Excel filters/slicers for: - 📅 Order
Date - 🚚 Delivery Date - 🎉 Occasion

These filters allow users to dynamically analyze the dashboard based on
selected dates, delivery periods, and occasions.

## 🛠️ Tools & Features

* Microsoft Excel
* PivotTables
* PivotCharts
* Slicers
* Timeline/Date Filters
* Excel formulas and calculations
* Dashboard design and KPI cards

## 📊 Data Analysis

The project analyzes customer orders, revenue, products, categories,
occasions, cities, order timing, and delivery performance to identify
sales trends and business performance.

## 🚀 How to Use

1. Open the Excel dashboard.
2. Use the **Order Date** or **Delivery Date** filters.
3. Select an **Occasion** from the slicer.
4. Observe how the KPIs and charts update dynamically.
5. Use the dashboard to compare revenue, products, categories, months,
   and cities.

## 📸 Dashboard Preview

The dashboard provides a clean, interactive view of FNP sales
performance with KPI cards, charts, and slicers.

## 👨‍💻 Project Type

**Excel Data Analytics / Business Intelligence Dashboard**

## ⭐ Skills Demonstrated

Excel Dashboarding • Data Analysis • PivotTables • PivotCharts • Slicers
• Data Visualization • KPI Reporting • Business Insights
